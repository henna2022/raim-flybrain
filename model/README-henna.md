## 틱택토 783 버전 (2026-11-04, `FLYWIRE=783`)
`FLYWIRE=783 python ttt_run.py 0 5`(seed 1도) → `FLYWIRE=783 python ttt_train.py`. 결과는 ttt783/ (630은 ttt/ 그대로).
783은 이름표가 다 붙어 감각 뉴런 16,352개(630은 8,126개)를 18묶음으로 나누고, 읽는 하행·운동 뉴런 1,409개(630은 1,171개). 묶음당 입력이 두 배. 판마다 읽는 뉴런 스파이크 합 1,415 → 1,991개(늘어난 몫은 거의 새 읽는 뉴런 238개. 630과 같은 1,171개만 세면 1,415 → 1,438).
| 수가 중요한 판 3,191개 | 630 | 783 |
|---|---|---|
| 처음 보는 판: 초파리 뇌 | 54.8% | 52.7% |
| 처음 보는 판: 새 잡음으로 채점 | 51.4% | 46.2% |
| 처음 보는 판: 판 그대로 선형 | 53.6% | 53.6% |
| 처음 보는 판: 난수로 이은 신경망 5회 중앙값 | 87.0% | 87.3% |
| 처음 보는 판: 뇌 반응 뒤섞기 | 40.0% | 39.5% |
| 전시 표 + 규칙 도우미 2개(태블릿) | 94.2% | 94.1% |
| 아무 데나 두기 | 40.5% | 40.5% |
- 결론 두 줄은 그대로: 판 정보는 뇌 반응에 담김(52.7% > 뒤섞기 39.5%), 더 잘 두는 건 초파리 배선 때문 아님(판 선형 53.6%와 비슷하고 난수 신경망 87.3%보다 한참 낮음)
- 처음엔 "783은 잡음에 더 흔들림"으로 봤으나 아님: 새 잡음 하락 6.5%p는 seed 0으로 학습·seed 1로 채점한 한 방향 값. 방향을 바꾸면 2.5%p(630은 3.5 / 2.9%p). 판 사이 거리 / seed 사이 거리(r_ttt)도 783이 더 큼(1.17 대 1.13). 새로 든 읽는 뉴런 238개는 신호/잡음 중앙값이 오히려 높음(1.53 대 1.07)
- 진짜 차이는 정확도: 처음 보는 판이 seed 두 방향 모두 783이 낮음(630 54.8·57.0%, 783 52.7·52.6%)
- 원인은 배선이 아니라 감각 입력 쪽: 783 배선에 630과 같은 감각 뉴런 8,126개·같은 순서·같은 18묶음을 넣으면(`FLYWIRE=783 FLYWIRE_SENS=630`, 결과 ttt783s630/) 55.3·56.2%로 630과 같음(630과 같은 읽는 뉴런 1,171개만 쓰면 55.4·56.9%, 스파이크 합 1,417로 630 1,415와 같음)
- 묶음 운 대조(`FLYWIRE_SHUF=1`: 감각 뉴런은 그대로, 18묶음에 나누는 무작위 순서만 바꿈). 783 배선, 처음 보는 판 seed 두 방향 평균:

| | 묶음 순서 0 | 묶음 순서 1 |
|---|---|---|
| 630 감각 뉴런 8,126개 (ttt783s630/, ttt783s630g1/) | 55.7% | 56.4% |
| 783 감각 뉴런 16,352개 (ttt783/, ttt783g1/) | 52.7% | 54.2% |

- 묶음 운은 0.7~1.5%p, 입력 차이는 평균 2.6%p. 네 번 모두 630 입력이 위라 감각 입력 효과가 있는 쪽으로 기움. 다만 칸마다 두 번씩이라 확정은 아님
- 783에서 새로 든 감각 뉴런 8,226개 중 8,105개가 눈의 광수용체(R1-6 6,024·R7 1,050·R8 1,031). 630에선 ID가 바뀌어 이름표가 안 붙던 것. 그래서 783 기본 입력은 66%가 시각(630 입력은 34%). 차이는 '두 배'보다 '광수용체로 쏠린 구성' 탓일 가능성이 큼(추정)
- 결정(2026-11-04): 783 틱택토는 감각 뉴런 16,352개 전체(기본값, ttt783/)를 씀. '감각 뉴런 전체'라 설명이 쉽고 결론은 그대로. 630의 8,126개는 ID가 우연히 안 바뀐 뉴런이라 고를 이유가 약함
- 그래서 '처음 보는 판' 정확도에는 ±1.5%p쯤 묶음 운이 섞여 있음. 판 그대로 선형(53.6%)과는 운 안에서 비슷한 수준이라 '낮다'가 아니라 '비슷하다'로 말해야 안전. 난수 신경망(87%)보다 한참 낮다는 결론은 그대로
- 입력을 맞추면 새 잡음 하락은 오히려 큼(7.2 / 5.3%p, 평균 6.2%p. 630 3.5 / 2.9%p). r_ttt는 1.12로 630(1.13)과 같아 반응의 잡음 크기는 같음. 하락 값이 seed에 따라 크게 흔들리는 탓으로 봄(추정)
- 관문 G2(새 잡음 하락 5%p 이하)는 한 방향만 재서 seed에 따라 크게 흔들림. 두 방향 평균으로 보는 게 안전함
