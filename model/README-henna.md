### 2026-11-04 783 버전 (`python try_loom.py 783`, 결과 results/try783)
783에서는 오른쪽 LPLC2가 102개 잡힘(이름표가 다 붙어서. 630에서 지금 이름표로 세면 87개). 630과 같은 87개만 넣은 공정 비교도 함(저장 안 함).
| 읽는 뉴런 | 630 (87개) | 783 (같은 87개) | 783 (102개, 앞으로 쓸 것) |
|---|---|---|---|
| DNp01 좌/우 | 85 / 124 Hz | 83 / 123 Hz | 89 / 133 Hz |
| DNp04 | 117 Hz | 117 Hz | 129 Hz |
| DNp06 | 2 / 60 Hz | 3 / 52 Hz | 5 / 59 Hz |
